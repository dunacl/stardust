## Published sources

The Classic tier (`crates/sg-accrete`) was written from Dole (1969), Fogg (1985),
Hart (1978) and Kothari (1936); see
[`docs/accretion-model-spec.md`](docs/accretion-model-spec.md).

The coefficients in `crates/sg-stellar/src/evolution/tables.rs` and the test
values in `crates/sg-stellar/tests/data/` come from the SSE package of Hurley,
Pols & Tout; see `reference/sse/README.md`.

## Earlier versions

Before the first public release the Classic tier was a port of StarGen. That code
and the output of that program were removed from this repository and its whole
git history before publication, and no part of them is in any build.
